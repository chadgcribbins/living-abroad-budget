# Living Abroad Budget - Implementation Experiments

This folder contains earlier versions and alternative implementations of the Living Abroad Budget app.

## Overview

**Goal:** Track evolution of the budgeting tool and preserve early implementations for reference.

## Implementations

### 1. Main Implementation (Current)
**Location:** Parent directory (`/`)
**Status:** ✅ Active - In Development
**GitHub:** https://github.com/chadgcribbins/living-abroad-budget

**Key Features:**
- International relocation budgeting (Portugal NHR focus)
- Multi-currency income modeling
- Housing, education, healthcare modules
- Zustand state management (migrated from Context API)
- Next.js 14, React, TypeScript

**Last Updated:** June 2025
